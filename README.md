# Habbo CMS Simple

Mini CMS front-end inspiré d'Habbo pour publier des news, gérer des statuts (publié/brouillon) et garder les données dans le navigateur via `localStorage`.

## Démarrer

```bash
python -m http.server 8000
```

Puis ouvrir `http://localhost:8000`.

## Fonctionnalités

- Tableau de bord avec statistiques.
- Gestion de news (ajout, publication, suppression).
- Démo réinitialisable avec un bouton.
